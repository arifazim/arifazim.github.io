What I Build
Most of my recent work has been around production AI and the infrastructure underneath it.

I have built hybrid RAG systems using FAISS, BM25, reranking, grounding checks, and evaluation pipelines. One of these systems now handles more than 10,000 sessions a day and helped reduce support costs by about $1.3M a year. Resolution rates went from 42% to 68%, while CSAT moved from 3.6 to 8.2.

I built a LangGraph routing agent for high-volume support workflows, with intent routing, guardrails, retry budgets, semantic caching, and LangSmith tracing. It reduced escalations by 65% across more than 8,000 sessions a day, with task completion above 99%.

I also built an evaluation system around LLM-as-judge scoring, grounding checks, safety tests, and CI/CD gates. The goal was simple. Catch bad model behavior before it reaches production. Evaluation time dropped by about 70%, and the pipeline caught three regressions before release.

Another project involved automated document redaction for public-sector workloads. The system processes more than 50,000 documents a month using AWS Textract, Comprehend, custom NLP, and multiple quality checks. It cut manual audit work by about 80%.

There is a fair amount of infrastructure behind all of this. Azure AI Foundry, AWS Bedrock, Azure Search, PostgreSQL, containers, CI/CD, observability, APIs, authentication, access control, and the usual collection of things that become very important once an AI prototype has to survive real users.

Forward-Deployed Engineering
Some of my recent work has been close to the customer and the actual operating environment.

One example was an Azure Search RAG system with department-level permissions and multi-agent document workflows. The system collects and classifies documents, then limits retrieval according to existing authorization boundaries.

Another was an eight-pass redaction platform spanning Azure AI Foundry and AWS Bedrock. The challenge was not simply detecting PII. Documents arrived in different formats, with different OCR quality, layouts, images, and regulatory requirements. The system had to deal with that mess without making every workflow a custom project.

That work included DOJ, HIPAA, and public-sector requirements, with the usual tradeoff between finding every sensitive entity and avoiding unnecessary redaction.
